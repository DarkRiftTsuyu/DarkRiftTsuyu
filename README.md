### 🎤 Karaokify

An attempt to solve the extremely important problem of:

> **"Why isn't there an easy way to turn a song + lyrics into an Melody Mania chart?"**

Karaokify takes audio and lyrics and works towards automatically generating SingStar / MelodyMania-style karaoke charts.

Current pipeline:

```text
song.mp3
   │
   ├──► vocal separation
   │
   ├──► pitch detection
   │
   ├──► lyric alignment
   │
   └──► 🎤 karaoke chart
```

WORK IN PROGRESS
